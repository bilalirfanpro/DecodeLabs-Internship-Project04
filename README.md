## Overview
This project turns raw data into clear visuals. I chose the chart type that best fits each question and used the charts to highlight the key insights in the data.

## Files in this repository

| File | Description |
|------|-------------|
| `Data_Visualization_Project4.xlsx` | The dataset with the charts and visualizations |

## Charts created

| Chart type | Used for | Insight |
|------------|----------|---------|
| Bar chart | Comparing categories | [e.g. which category sells the most] |
| Line chart | Showing trends over time | [e.g. how sales changed month by month] |
| Pie chart | Showing share of a total | [e.g. each region's share of revenue] |

## Why these charts?
- **Bar charts** make it easy to compare values across categories.
- **Line charts** show how something changes over time.
- **Pie charts** show how parts make up a whole, and work best with only a few categories.
